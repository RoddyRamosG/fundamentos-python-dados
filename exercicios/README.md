# Exercícios de Python

## Calculadora de média

Programa que solicita três notas, calcula a média aritmética e
classifica o resultado como aprovado, recuperação ou reprovado.

### Conceitos praticados

- Entrada e conversão de dados;
- Listas;
- Funções;
- Condicionais;
- Tratamento de erros;
- Validação de valores.
