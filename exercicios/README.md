# Exercícios de Python

## Calculadora de média

Programa que solicita três notas, calcula a média aritmética e
classifica o resultado como aprovado, recuperação ou reprovado.

### Conceitos praticados

- Entrada e conversão de dados;
- Listas;
- Funções;
- Condicionais;
- Tratamento de erros;
- Validação de valores.

## Conversor de temperatura

Programa que realiza conversões entre Celsius e Fahrenheit.

### Conversões disponíveis

- Celsius para Fahrenheit;
- Fahrenheit para Celsius.

### Conceitos praticados

- Funções;
- Parâmetros e retornos;
- Condicionais;
- Laços de repetição;
- Tratamento de erros;
- Operações matemáticas;
- Formatação de resultados.

### Como executar

`python exercicios/conversor_temperatura.py`
